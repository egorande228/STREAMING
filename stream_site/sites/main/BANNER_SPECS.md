# KingLive Banner Specs

Current site layout does not use banners. If banners return, use these sizes instead of the old right rail set.

## Recommended Slots

| Slot | Desktop asset | Tablet asset | Mobile asset | Notes |
| --- | ---: | ---: | ---: | --- |
| Match-center strip | 1180x120 | 728x90 | 343x96 | Best placement between hero and match list. Keep text large and sparse. |
| Inline match break | 1180x160 | 728x140 | 343x180 | Use after 4-6 matches only, not above the first screen. |
| News sponsor card | 360x220 | 320x200 | 280x180 | Should match news-card proportions if inserted into the carousel. |
| Match popup compact | 320x80 | 320x80 | 300x80 | Optional small sponsor strip under match stats, never above the player button. |
| Footer notice strip | 1180x180 | 728x160 | 343x200 | Lowest-priority placement near the legal notice. |

## Do Not Use

| Old size | Reason |
| ---: | --- |
| 300x600 | Breaks the current single-column match-center composition. |
| 300x250 right rail | Forces a two-column layout and clips on common laptop widths. |
| 970x90 top banner | Looks stretched above the hero and competes with navigation. |
| 970x250 bottom banner | Too visually heavy compared with the news and legal sections. |

## Export Rules

- Use `webp` at 2x source quality when possible.
- Keep safe text inside 6% horizontal padding and 10% vertical padding.
- Avoid tiny benefit lists; the current design needs one strong message per banner.
- Provide English-only creative unless localization is explicitly needed.
